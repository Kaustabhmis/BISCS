What a watermark is for

A watermark is a visible label across your pages. It does three useful jobs:

  • Signals status: "DRAFT" tells everyone this is not the final version; "SAMPLE" or "SPECIMEN" stops a document being mistaken for an original.
  • Signals ownership: a faint company logo on a proposal or a design portfolio shows where it came from.
  • Limits reuse of copies: a line such as "Submitted to XYZ Bank for home loan, 02-11-2026" across an ID copy makes it awkward to reuse for something else.

What a watermark is not: a lock. Anyone with editing software may manage to remove or cover it. Treat it as a strong label and deterrent, and control who receives the file for real security.

How to add a watermark step by step

  1. Open Watermark PDF and choose your PDF.
  2. Choose Text or Image.
  3. For text, type your watermark and set the Font size and Colour. For an image, choose a PNG or JPG and set its Width as a percentage of the page.
  4. Choose a Layout: Center, Diagonal (corner to corner) or Tiled (repeated across the page). For Center and Tiled, you can set the rotation angle.
  5. Adjust Opacity. The default is 30%.
  6. In Pages, leave it empty for all pages or type a range.
  7. Check the preview, then apply and download.

Choosing the right layout

Layout Effect Good for
Diagonal One large mark from corner to corner DRAFT, CONFIDENTIAL, COPY
Center One mark in the middle at the angle you choose Logos, subtle branding
Tiled The mark repeats across the whole page ID copies, design proofs, documents likely to be cropped

Tiled is the hardest to crop out, which is why it suits identity documents and creative work shared for review.

Watermarking ID copies before sharing

India runs on photocopies of identity documents: Aadhaar for a SIM card, PAN for a bank account, a driving licence for a car rental. Once shared, those copies can travel further than you intended.

A common, sensible habit is to write the purpose and date across the copy. With this tool you might use the text "For SBI savings account KYC only – 02 Nov 2026" in Tiled layout at 20–25% opacity. Keep it light enough that the recipient can still read the details they legitimately need. If the copy came from DigiLocker as a PDF, you can watermark it directly; if it is a photo, convert it first with Images to PDF.

Some organisations have their own rules about what a copy must show, so if a watermarked copy is rejected, ask what they require.

Common mistakes to avoid

  • Opacity too high. A dark, solid watermark can make the document unreadable, defeating its purpose.
  • Covering key details. On forms and ID copies, make sure names, numbers and photos remain visible.
  • Watermarking before final edits. The watermark is part of the page once saved. Finish editing, page ordering and numbering first.
  • Using Indian-language text. Text watermarks use a standard font that covers English and Western characters only; unsupported characters become "?". Use an image watermark for other scripts.
  • Relying on it as security. For truly sensitive files, share less: remove unnecessary pages instead of only marking them.

Text watermark ideas

  • DRAFT, or DRAFT v2, for documents under review.
  • CONFIDENTIAL, or INTERNAL USE ONLY, for office reports.
  • SAMPLE, or SPECIMEN, for templates and demo invoices.
  • PAID, or CANCELLED, for internal record copies of invoices.
  • Your name and the recipient for review copies of creative work, for example "Shared with Ravi, preview only".

Tips for a clean logo watermark

  • Use a PNG with a transparent background, so only the logo appears and not a white box.
  • Start with a width of about 30–40% of the page for a centred logo.
  • Lower the opacity to around 15–20% so it reads as a background element.
  • Pair it with Add Page Numbers for proposals that need both branding and numbering.

Example: sending a draft agreement for review

A startup in Kolkata is circulating a draft vendor agreement to three partners. To avoid anyone signing an outdated version, the founder adds "DRAFT – NOT FOR SIGNATURE" in the Diagonal layout at 25% opacity, in grey. When the final version is agreed, the clean, unwatermarked file is the one sent for signing with Sign PDF.

Watermark before or after other steps?

Order matters, because a watermark becomes part of each page once it is saved.

  1. Edit content, fill forms and fix any typos first.
  2. Arrange, merge, remove or rotate pages.
  3. Add page numbers if needed.
  4. Add the watermark.
  5. Compress last, if the file is too large to send.

If you watermark first and then remove a page, nothing breaks, but if you watermark and then need to edit the wording underneath, you will be working around the mark. Keeping a clean, unwatermarked master copy on your device avoids that problem entirely: you can always produce a fresh watermarked copy for each recipient.

Privacy

Watermarking is often done precisely because a document is sensitive, so it would be odd to upload it to a stranger's server to do it. This tool stamps the pages inside your browser and saves the result to your device. Nothing is sent anywhere.

Frequently asked questions

Should I watermark copies of my Aadhaar or PAN card?

Many people add a line such as For bank KYC only, with the date, before sharing ID copies. It does not make misuse impossible, but it marks the copy’s intended purpose and makes casual reuse harder. Place the text so it crosses the document without hiding the details the recipient needs to read.

Can a watermark be removed?

A determined person with editing software may be able to remove or cover a watermark, because it is drawn on top of the page. A watermark is a deterrent and a label, not a security lock. For real protection, limit who receives the file.

What opacity should I use?

Around 20 to 35 per cent works for most documents. The text stays readable while the watermark is clearly visible. Go lower for busy pages full of tables and higher for simple letters, and check the live preview before downloading.

Can I watermark only some pages?

Yes. Type the page numbers or ranges in the Pages box, for example 1-3, 7. Leave it empty to watermark every page. This is handy when only the main pages of a bundle need marking.

Can I use Hindi text as a watermark?

Text watermarks use the standard bold Helvetica PDF font, which does not include Hindi or other Indian scripts. As a workaround, create an image of the text, for example a PNG, and use the Image watermark option instead.
