How to Convert Plain Text or a TXT File to a Clean PDF

Paste text or open a .txt file and turn it into a tidy, printable PDF with your choice of font, size, spacing, margins and page numbers. Free and private online.

Open Text to PDF

To convert text to a PDF, open Text to PDF, type or paste your text (or open a .txt file), choose a font, size, line spacing, page size and margins, and click Create PDF. You get a clean, printable document with optional page numbers at the bottom.

It is a quick way to turn notes, logs, lists or copied text into a tidy document. And because it runs in your browser, your text is never uploaded.

When text to PDF is the right tool

Plain text is everywhere: notes on your phone, a message you drafted, a log file from software, an exported list of addresses. A PDF makes it shareable and printable without anyone needing a particular app. Useful cases include:

  • Meeting notes to circulate after a call.
  • Simple letters, such as a leave application or a request to a housing society.
  • Software logs and config files for a support ticket, where a monospaced font keeps everything aligned.
  • Lists: guest lists, packing lists, inventory counts.
  • Drafts of articles or stories for printing and proofreading on paper.
  • CSV exports you want to print as a simple, fixed-width listing.

How to create a PDF from text step by step

  1. Open Text to PDF.
  2. Type or paste your text into the editor, or click Open .txt file to load one (.txt, .md, .csv and .log are accepted).
  3. Choose a Font: Sans, Serif or Mono.
  4. Set the Font size and Line spacing (Single, 1.15, 1.5 or Double).
  5. Pick the Page size (A4 or Letter) and Orientation (Portrait or Landscape).
  6. Set the Margins in millimetres.
  7. Keep Add page numbers ticked if you want them.
  8. Click Create PDF and download it. The result shows the number of pages and lines.

Choosing the right settings

Content Font Size Spacing Orientation
Letter or application Serif 11–12 pt 1.15 Portrait
Meeting notes Sans 11 pt 1.15 Portrait
Proofreading draft Serif 12 pt 1.5 or Double Portrait
Logs, code, config Mono 9–10 pt Single Landscape for long lines
Wide CSV listing Mono 8–9 pt Single Landscape

Double spacing is a classic choice for anything you will mark up with a pen, because it leaves room between lines.

Common mistakes to avoid

  • Pasting Hindi, Bengali or the ₹ symbol. The standard PDF fonts cannot show them, and they become "?". The tool lists unsupported characters before you create the file; write "Rs." instead of ₹ and keep the text in English.
  • Expecting formatting to carry over. Bold, italics and bullets from a word processor are lost when copied as plain text. Markdown symbols stay as typed.
  • Using a proportional font for aligned text. Columns lined up with spaces only stay aligned in Mono.
  • Very small margins. Many printers cannot print right to the edge. Margins of 15–20 mm print reliably.
  • Very long lines in portrait. Long log lines wrap and become harder to read. Switch to landscape or reduce the font size.

If you want a formatted document, write it in a word processor and convert it. If you just want your words neatly on paper, Text to PDF is faster.

How page breaks and wrapping work

The tool measures each line against the page width and wraps long lines automatically at word boundaries, so text never runs off the page. When a page fills up, the text continues on the next page, and page numbers (if switched on) are added at the bottom centre in a lighter grey. Your own line breaks and blank lines are kept exactly as you typed them, which means you control paragraphs and spacing simply by pressing Enter.

There is no automatic way to force a page break at a particular point. If you need a new page for a new section, add a few blank lines, or create separate PDFs and join them with Merge PDF.

Checklist before you create the PDF

  • Spelling checked in the editor (the browser's spell check is active).
  • No Hindi text, emojis or ₹ symbols; the tool will flag any unsupported characters.
  • Font suits the content: Mono for code and aligned lists, Serif or Sans for prose.
  • Orientation set to landscape if lines are very long.
  • Page numbers on for multi-page documents, off for one-page letters.

Tips for neater documents

  • Leave a blank line between paragraphs; the tool keeps your line breaks exactly as typed.
  • Put the date and subject at the top in the text itself, as you would on paper.
  • For multi-page notes, keep page numbers on so printed pages can be put back in order.
  • Want to combine the result with other documents? Use Merge PDF afterwards.

Private by design

Your text is turned into a PDF by code running in your browser. It is not uploaded or stored, which matters if the notes contain personal or business information. The live character counter and the PDF output all work on your device, even if your connection drops after the page loads.

Frequently asked questions

Can I convert a .txt file directly?

Yes. Click Open .txt file, or drop the file on the page. The tool also accepts .md, .csv and .log files as plain text. The content loads into the editor, where you can check or tweak it before creating the PDF.

Can I write in Hindi or other Indian languages?

Not in this tool at the moment. It uses the standard PDF fonts, which cover English and Western characters. Hindi and other non-Latin scripts, and symbols like the rupee sign, appear as question marks, and the tool warns you before you create the PDF.

Does it keep bold, headings or bullet formatting?

No. It creates a clean plain-text document. Markdown symbols such as asterisks and hash signs appear as typed. Long lines wrap automatically to fit the page. For formatted documents, write in a word processor and use Word to PDF instead.

Which font should I choose?

Sans (Helvetica) is clean and modern for notes and letters. Serif (Times) suits formal letters and longer reading. Mono (Courier) keeps every character the same width, which is ideal for code, logs and text that is aligned with spaces.
