Creating a UPI payment QR code

A UPI QR code lets customers pay you by scanning with any UPI app. The format and rules for UPI payment QR codes are set by the National Payments Corporation of India (NPCI), which runs UPI. The BISCS tool creates a standard UPI payment link containing:

  • UPI ID (VPA), such as shopname@okbank. This is required.
  • Payee name, shown to the payer.
  • Amount, optional. Leave it blank so the payer can type any amount, or fill it for a fixed fee.
  • Note, optional, such as "Class 10 tuition – November".

Before you print a UPI QR code

  1. Verify the UPI ID letter by letter. One wrong character sends money to someone else, or nowhere.
  2. Scan it with your own UPI app and check the name that appears is yours or your business's.
  3. Make a small test payment, such as ₹1, and confirm it reaches the right bank account.
  4. Keep a fixed-amount code only for fixed fees. For a shop counter, a code without an amount is more flexible.

A self-made UPI code is fine for small sellers, tutors and personal collections. If you need business features like instant payment alerts, settlement reports or a sound box, use the merchant QR issued by your bank or payment provider.

Safety tip for customers and sellers

You never need to scan a QR code or enter your UPI PIN to receive money. The PIN is only for sending. Fraudsters sometimes send a QR code claiming it will credit a refund or prize. Do not scan it. Shop owners should also check from time to time that nobody has stuck a different QR code over theirs.

Wi-Fi QR codes for home and business

Enter your network name (SSID), password and security type (usually WPA/WPA2/WPA3). Tick Hidden network if your router does not broadcast its name. Guests scan the code with their phone camera and connect without typing a long password. Print it for a guest room or café table, and make a new one whenever you change the password.

Error correction, size and colours explained

QR codes contain extra data so they still scan if part of the code is damaged or covered.

Level Recovers up to Best for
Low (L) About 7% Clean screens, maximum data
Medium (M) About 15% Most everyday uses
Quartile (Q) About 25% Printed items that may get scuffed
High (H) About 30% Codes with a logo or rough handling

Higher levels make the pattern denser, so keep the content short where you can. A long URL produces a crowded code; a short link scans more easily.

Colours: dark modules on a light background scan best. The tool warns you if the contrast is low or if you have chosen light modules on a dark background, which some apps cannot read.

Margin: keep a clear border, called the quiet zone, of about four modules around the code. The default setting does this.

Common QR code mistakes

  • Not testing before printing hundreds of flyers or standees.
  • Printing too small, especially on visiting cards. Test at the final size.
  • Low contrast colours, like light grey on white or brand colours that are too similar.
  • Oversized logos covering too much of the pattern.
  • Long URLs with tracking clutter that make the code dense. Shorten them or remove unnecessary parameters.
  • Typos in a UPI ID or Wi-Fi password, which make the code useless or, worse, misdirect payments.

Practical tips

  • Add a short line of text beside the code, such as "Scan to pay" or "Scan for menu", so people know what to expect.
  • Use SVG for large prints like banners, so edges stay crisp.
  • If you want to measure scans from a campaign, add UTM tags to your link with the UTM Builder before creating the code.
  • For products and inventory, a linear barcode from the Barcode Generator may suit scanners better.
  • Add your UPI ID to bills made with the GST Invoice Generator so customers have it in writing too.

Frequently asked questions

Do QR codes from this generator expire?

No. The generator makes static QR codes: the information is stored inside the pattern itself, not on a server. The code works for as long as the content is valid, for example as long as the website or UPI ID exists. There are no scan limits or subscriptions.

Is a UPI QR code from this tool safe to use for my shop?

It creates a standard UPI payment link that UPI apps can read. Before printing it, scan it with a UPI app and check that the correct name appears, then make a small test payment. For business features such as payment alerts, settlement reports or a soundbox, use the merchant QR provided by your bank or payment provider.

Do I need to scan a QR code to receive money?

No. You never need to scan a QR code or enter your UPI PIN to receive money. A UPI PIN is only entered when you send money. If someone asks you to scan a code or enter a PIN to “receive” a payment or refund, it is a scam.

Can I add my logo to the QR code?

Yes. Upload an image as a centre logo and set its size from 10% to 30% of the code. The generator automatically switches to the highest error correction level so the code can still be read with part of it covered. Always test-scan before printing.

What size should a printed QR code be?

A common rule of thumb is that the code should be at least about one tenth of the scanning distance, and not smaller than roughly 2 cm across for close-up scanning. A code on a poster read from a metre away should be around 10 cm wide. Download the 2048 px PNG or the SVG for print.
